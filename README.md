# dmol

A small research-oriented library with capabilities for differential geometry functionality, optimization, and optimization layers for safety-constrained robotics. Note that the differentiable manifold optimization layer (DMOL) is the intended application that this code was developed for with use in input spaces with a cost metric. This code is by no means production-ready.

NOTE: this repo is still in a state of constant flux due to needs of the author

Use of any code in this repository is at your own risk but its use (although not expected) must be cited. Enjoy!
